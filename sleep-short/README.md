# «7 дней без сна» — вертикальный 2D-мультфильм (Shorts / TikTok)

**Готовый файл:** `sleep_7_days_short.mp4` — 1080×1920, 30 fps, 92 с, H.264 + AAC, ~35 МБ.
**Обложка:** `cover.png` (1080×1920).
**Озвучка:** `audio/vo_*.mp3` — 8 реплик, энергичный мужской голос (RU).

## Как это сделано
Ролик собран полностью программно, без стоковых видео: 9 нарисованных 2D-кадров
(единый персонаж в стиле Rick and Morty / Gravity Falls) превращены в «анимацию»
через движение камеры, монтаж, вспышки, тряску и глитч. Музыка и звуковые эффекты
синтезированы с нуля (numpy).

| Слой | Файл | Что делает |
|---|---|---|
| Раскадровка | `art/*.png` | 9 сцен + референс персонажа |
| Голос | `audio/vo_*.mp3` | озвучка по сценарию |
| Подготовка голоса | `build/prep_voice.py` | обрезка паузы, темп ×1.26, нормализация |
| План монтажа | `build/plan.py` | сцены, 24 шота, тайминги титров, SFX → `build/timeline.json` |
| Музыка + SFX | `build/audio_build.py` | синтез трека (день ото дня фальшивее и злее), дакинг под голос → `build/mix.wav` |
| Видео | `build/video_build.py` | Ken Burns, бит-пульс, тряска, глитч, комикс-титры, рендер в mp4 |
| Графика | `build/gfx.py` | текст с обводкой, стикеры дня, батарейка, прогресс-бар, виньетка |

## Пересборка
```bash
pip install numpy pillow imageio-ffmpeg matplotlib   # ffmpeg берётся из imageio-ffmpeg
python3 build/prep_voice.py
python3 build/plan.py
python3 build/audio_build.py
GRAIN=0 CRF=22 PRESET=slow python3 build/video_build.py
```
Проверить отдельные кадры без полного рендера:
`python3 build/video_build.py --frames 150,1250,2680`

## Драматургия звука
- День 1–2: мажор, 124 BPM, бодрый арпеджио-лид.
- День 3: минор + тритоны, тремоло-пэд, 16-е хэты.
- День 4: биткраш, глитч, стабы.
- День 5: расстройка до 40 центов, случайные «призрачные» ноты, реверс-свеллы.
- День 7: дрон, аритмичное «сердце», tape-stop.
- Финал: тёплое мажорное разрешение, музыкальная шкатулка.
