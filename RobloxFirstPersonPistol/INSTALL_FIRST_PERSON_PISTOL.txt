--------------------------------------------------------------------------------
1. ЧТО ПОЛУЧИТСЯ В ИГРЕ
--------------------------------------------------------------------------------
* При входе игрок СРАЗУ в первом лице (зум 0/0, третье лицо колесом запрещено).
* Родные руки/торс/шляпы персонажа спрятаны, чтобы не двоились.
* В кадре СЛЕВА виден пистолет + кисть + предплечье, ствол направлен ВПЕРЁД,
  как будто игрок реально держит его и целится.
* При ходьбе / беге оружие анимированно двигается: боб вверх-вниз, в стороны,
  лёгкий roll/pitch/yaw, сглаженный вход и выход из движения.
* В покое оружие «дышит»; при резком повороте головы инерционно отстаёт
  (работает от мыши, геймпада и тача, даже без лок-курсора).
* CTRL (левый ИЛИ правый) плавно, за 0.28 сек, переставляет пистолет НАПРАВО
  вместе с рукой. Повторный CTRL возвращает НАЛЕВО. Есть кнопка «⇄» для телефона.
* Бонус: ЛКМ = косметическая отдача + дульная вспышка (УРОНА НЕ НАНАСИТ).
* Два режима рендера: «Camera» (свет мира 1:1) и «Viewport» (оружие никогда
  не зарезается об стену). Переключается одной строкой в FPSettings.

  «ViewmodelBuilder» (это имя объекта в Studio, а не имя файла на диске).
  Имя LocalScript и Script может быть любым, но выше даны рекомендуемые.

  НЕ вставляй в Workspace, НЕ вставляй в StarterGui, НЕ вставляй в Tool,
  НЕ вставляй в StarterCharacterScripts: LocalScript обязан лежать именно в
  StarterPlayer > StarterPlayerScripts, иначе camera/PlayerGui подхватятся
  с задержкой и будет рывок на первом кадре.

  ДОПОЛНИТЕЛЬНО В STUDIO (Properties -> StarterPlayer), один раз руками:
      CameraMode            = LockFirstPerson
      EnableMouseLockOption = false     (чтобы Shift не кидал камеру в плечо)
  Серверный скрипт выставит это и сам, но в Play Solo руками надёжнее.

3. ПОРЯДОК УСТАНОВКИ (5 шагов)
--------------------------------------------------------------------------------
  1) Создай 4 объекта по дереву выше (правый клик -> Insert Object).
  2) Переименуй два ModuleScript'а ТОЧНО как в дереве.
  3) Скопируй код из раздела «ПОЛНЫЙ ИСХОДНЫЙ КОД» ниже (или просто возьми
     готовые .lua-файлы из этой же папки репозитория) и вставь в каждый объект.
  4) File -> Save to Roblox (Ctrl+S) / Publish.
  5) F5 (Play) или Play Here. Готово.

  Порядок запуска внутри кода уже соблюдён: сервер сначала фиксирует
  LockFirstPerson -> клиент ждёт PlayerGui/CurrentCamera -> строит модель ->
  вешает RenderStep с приоритетом 201 (ПОСЛЕ камеры Roblox, приоритет 200).

--------------------------------------------------------------------------------
4. УПРАВЛЕНИЕ
--------------------------------------------------------------------------------
  W A S D / стик     -> ходьба, оружие качается (боб)
  Мышь / палец       -> поворот головы, оружие инерционно отстаёт
  LeftCtrl / RightCtrl -> перекинуть пистолет на другую руку (туда-обратно)
  Кнопка «⇄» (справа внизу) -> то же самое на телефоне/планшете
  ЛКМ                -> косметическая отдача + вспышка (без урона)

--------------------------------------------------------------------------------
5. ТОНКАЯ НАСТРОЙКА (всё в FPSettings.lua, остальные файлы не трогаем)
--------------------------------------------------------------------------------
  RENDER_MODE = "Camera"   -> поменяй на "Viewport", если у стенок клиппится.
  LEFT_OFFSET / RIGHT_OFFSET -> положение: -Z вперёд, -X лево, +X право, -Y низ.
  BOB_*                    -> амплитуда и частота походной анимации.
  SWAP_TIME                -> скорость переезда по Ctrl.
  SWAP_KEYS                -> замени на {Enum.KeyCode.Q}, если Ctrl занят кроучем.
  LOOK_CAMERA_GAIN         -> насколько сильно оружие отстаёт от поворота.
  FIELD_OF_VIEW = 75       -> классический FPS-угол.
  LOCK_MOUSE = true        -> залочить курсор, как в настоящем шутере.
  SHOT_SOUND_ID            -> вставь "rbxassetid://...", чтобы ЛКМ звучал.
  COLOR_SKIN_*             -> цвет кожи автоматически берётся из BodyColors.

--------------------------------------------------------------------------------
6. КАК ЭТО УСТРОЕНО (почему именно так в 2026)
--------------------------------------------------------------------------------
* НОЛЬ Weld / Motor6D / Humanoid / Animator. Все детали Anchored + CanCollide=false.
  Каждый кадр ОДИН baseCFrame пересчитывает CFrame каждой детали. Нет физики ->
  нет лага на кадр, нет дёрганья на 144/240 FPS, ничего не ломается на респавне.
* BindToRenderStep(..., Enum.RenderPriority.Camera.Value + 1) гарантирует, что
  стандартный PlayerModule уже посчитал CFrame камеры до нас.
* Зеркало правой руки считается аналитически (отражение по X + инверсия Y/Z
  поворотов), поэтому Ctrl даёт плавный МОРФИНГ, а не подмену второй модели.
* Цвет руки читается из BodyColors.LeftArmColor -> совпадает со скином игрока.
* HIDE_REAL_CHARACTER вешает LocalTransparencyModifier = 1 на BasePart'ы и
  слушает DescendantAdded, чтобы поздние аксессуары тоже прятались.
* Режим «Viewport» = ScreenGui -> ViewportFrame -> WorldModel -> отдельная
  Camera, CFrame которой каждый кадр равен игровой. Мир физически не может
  перекрыть оружие. Идеально для узких коридоров и дверей.
* Серверный скрипт вообще не трогает игровую логику: только CameraMode/зум.

--------------------------------------------------------------------------------
7. ЕСЛИ ЧТО-ТО НЕ ТАК
--------------------------------------------------------------------------------
  Видны «настоящие» руки персонажа
      -> проверь HIDE_REAL_CHARACTER = true и что LocalScript лежит в
         StarterPlayerScripts (не в StarterCharacterScripts).
  Пистолет зарезается об стену / дверь
      -> FPSettings: RENDER_MODE = "Viewport".
  Слишком близко / далеко / высоко
      -> крути LEFT_OFFSET и RIGHT_OFFSET (третье число = -Z, глубина).
 Ctrl не реагирует
      -> другой скрипт перехватил ввод. Поменяй SWAP_KEYS, например на
         { Enum.KeyCode.Q, Enum.KeyCode.E }, либо возвращай Sink вместо Pass.
  Хочу прицеливание (ADS) на ПКМ, спринт-анимацию, настоящую стрельбу,
  патроны, перезарядку, урон, рейкаст, анти-чит, репликацию выстрела
      -> просто скажи. Добамлю отдельным большим китом с RemoteEvent +
         серверным FastCast/Raycast + валидацией + звуками + тряской камеры.
  Игра в Studio показывает третье лицо на 1 кадр
      -> выставь StarterPlayer.CameraMode руками (см. п.2), сервер тоже ставит.

--[[
    ViewmodelBuilder.lua
    ModuleScript -> StarterPlayer > StarterPlayerScripts

    ПРОЦЕДУРНЫЙ ПИСТОЛЕТ + КИСТЬ + ПРЕДПЛЕЧЬЕ.
    Никаких Weld / WeldConstraint / Motor6D / Humanoid / Animator.

    Почему так (best practice 2026):
      * все детали Anchored = true, CanCollide = false, CastShadow = false;
      * каждый кадр мы ОДНИМ baseCFrame пересчитываем CFrame каждой детали;
      * нет физики -> нет лага на 1 кадр, нет дёрганья при 240 FPS,
        нет «welds ломаются на респавне»;
      * зеркало для правой руки считается аналитически (отражение по X),
        поэтому переезд Ctrl получается плавным морфингом, а не подменой модели.

    Все локальные координаты заданы ОТНОСИТЕЛЬНО центра рукояти (root).
    Ствол смотрит в -Z (вперёд от камеры).
--]]

local Settings = require(script.Parent:WaitForChild("FPSettings"))

local Builder = {}
Builder.__index = Builder

local function V(x, y, z)
    return Vector3.new(x, y, z)
end

local function R(x, y, z)
    return Vector3.new(math.rad(x), math.rad(y), math.rad(z))
end

local function mirrorVec(v)
    return V(-v.X, v.Y, v.Z)
end

local function mirrorRot(r)
    -- Отражение по плоскости YZ: X-поворот сохраняем, Y и Z инвертируем.
    return V(r.X, -r.Y, -r.Z)
end

local function cfFromRot(pos, rot, cylinderAlign)
    local cf = CFrame.new(pos) * CFrame.Angles(rot.X, rot.Y, rot.Z)
    if cylinderAlign then
        -- Цилиндр в Roblox по умолчанию вытянут по Y -> доворачиваем в Z.
        cf = cf * CFrame.Angles(math.rad(90), 0, 0)
    end
    return cf
end

-- ---------------------------------------------------------------------
-- Создаёт одну деталь и запоминает её ЛЕВЫЙ и ПРАВЫЙ локальные CFrame.
-- ---------------------------------------------------------------------
function Builder:_add(s)
    local part = Instance.new("Part")
    part.Name            = s.Name
    part.Size            = s.Size
    part.Shape           = s.Shape or Enum.PartType.Block
    part.Material        = s.Material or Enum.Material.SmoothPlastic
    part.Color           = s.Color
    part.Transparency    = s.Transparency or 0
    part.Anchored        = true
    part.CanCollide      = false
    part.CastShadow      = false
    part.Massless        = true
    part.Parent          = self.Model

    local leftCF, rightCF

    if s.LookAt then
        -- Для предплечья удобнее CFrame.lookAt: ось -Z смотрит на кисть.
        leftCF = CFrame.lookAt(s.Pos, s.LookAt)
        rightCF = s.Mirror
            and CFrame.lookAt(mirrorVec(s.Pos), mirrorVec(s.LookAt))
            or leftCF
    else
        leftCF = cfFromRot(s.Pos, s.Rot, s.CylinderAlign)
        rightCF = s.Mirror
            and cfFromRot(mirrorVec(s.Pos), mirrorRot(s.Rot), s.CylinderAlign)
            or leftCF
    end

    local rec = {
        Part             = part,
        LeftCF           = leftCF,
        RightCF          = rightCF,
        BaseTransparency = part.Transparency,
        IsFlash          = (s.IsFlash == true),
        IsSkin           = (s.IsSkin == true),
    }

    table.insert(self.Records, rec)

    if rec.IsSkin then
        table.insert(self.SkinParts, part)
    end

    if rec.IsFlash then
        self.FlashPart = part
        local light = Instance.new("PointLight")
        light.Name      = "MuzzleLight"
        light.Color     = Settings.COLOR_FLASH
        light.Brightness = 4
        light.Range      = 3.5
        light.Enabled    = false
        light.Parent     = part
        rec.Light        = light
        self.FlashLight  = light
    end

    return rec
end

-- ---------------------------------------------------------------------

    }

        Name = "Slide", Size = V(0.158, 0.078, 0.600),

    }

        Name = "SlideTopStripe", Size = V(0.022, 0.010, 0.500),

            Name = "SerrationR_" .. i, Size = V(0.012, 0.050, 0.012),

            Color = Settings.COLOR_METAL, Material = Enum.Material.Metal,

    end

    self:_add {
        Name = "Barrel", Size = V(0.075, 0.200, 0.075),
        Pos = V(0, 0.075, -0.550), Rot = R(0, 0, 0),
        Shape = Enum.PartType.Cylinder, CylinderAlign = true,
        Color = Settings.COLOR_METAL, Material = Enum.Material.Metal,
    }
    self:_add {
        Name = "MuzzleRing", Size = V(0.092, 0.035, 0.092),
        Pos = V(0, 0.075, -0.655), Rot = R(0, 0, 0),
        Shape = Enum.PartType.Cylinder, CylinderAlign = true,
        Color = Settings.COLOR_FRAME, Material = Enum.Material.Metal,
    }

-- ---------------------------------------------------------------------
-- ПУБЛИЧНОЕ API
-- ---------------------------------------------------------------------
function Builder.new(parent)
    local self = setmetatable({}, Builder)

    self._parent   = parent
    self.Visible   = true
    self.Records   = {}
    self.SkinParts = {}
    self.FlashPart = nil
    self.FlashLight = nil

    self.Model = Instance.new("Model")
    self.Model.Name   = Settings.VIEWMODEL_NAME
    self.Model.Parent = parent

    self:_build()
    return self
end

-- baseCF  : CFrame камеры * смещение * все анимации
-- blend   : 0 = левая рука, 1 = правая рука (плавно от TweenService)
-- flash   : 0..1, прозрачность вспышки
function Builder:Apply(baseCF, blend, flash)
    if not self.Visible then
        return
    end

    for _, r in ipairs(self.Records) do
        local localCF = r.LeftCF:Lerp(r.RightCF, blend)
        r.Part.CFrame = baseCF * localCF

        if r.IsFlash then
            r.Part.Transparency = 1 - flash
            if r.Light then
                r.Light.Enabled = flash > 0.02
            end
        end
    end
end

function Builder:SetSkin(color)
    for _, p in ipairs(self.SkinParts) do
        p.Color = color
    end
end

function Builder:SetParent(parent)
    self._parent = parent
    self.Model.Parent = self.Visible and parent or nil
end

function Builder:SetVisible(visible)
    self.Visible = visible
    self.Model.Parent = visible and self._parent or nil
end

function Builder:Destroy()
    self.Model:Destroy()
    table.clear(self.Records)
    table.clear(self.SkinParts)
end

return Builder

-- =====================================================================
-- ГЛАВНЫЙ ЦИКЛ (BindToRenderStep с приоритетом ПОСЛЕ камеры Roblox)

local function onRender(dt)
    local cam = ensureCamera()
    if not cam then
        return
    end

    -- В режиме Viewport держим свою камеру синхронной с игровой.
    if Settings.RENDER_MODE == "Viewport" and viewportCamera then
        viewportCamera.CFrame      = cam.CFrame
        viewportCamera.FieldOfView = cam.FieldOfView
    end

    local blend = math.clamp(sideValue.Value, 0, 1)

    -- ---------- Скорость / боб -------------------------------------
    local moveAmp = 0
    local hum = getHumanoid()
    if hum then
        local md = hum.MoveDirection
        local grounded = true
        pcall(function()
            grounded = (hum.FloorMaterial ~= Enum.Material.Air)
        end)

        if grounded and md.Magnitude > 0.01 then
            local horiz = 0
            local root = hum.RootPart
            if root then
                local ok, vel = pcall(function()
                    return root.AssemblyLinearVelocity
                end)
                if not ok or typeof(vel) ~= "Vector3" then
                    ok, vel = pcall(function()
                        return root.Velocity
                    end)
                end
                if ok and typeof(vel) == "Vector3" then
                    horiz = Vector3.new(vel.X, 0, vel.Z).Magnitude
                end
            end
            local ws = hum.WalkSpeed > 0 and hum.WalkSpeed or 16
            local ratio = math.clamp(horiz / ws, 0, 1.35)
            moveAmp = math.clamp(md.Magnitude, 0, 1) * ratio
        end
    end

    lastMoveAmp = lastMoveAmp
        + (moveAmp - lastMoveAmp) * math.clamp(dt * Settings.BOB_SMOOTH, 0, 1)
    bobPhase = bobPhase + dt * Settings.BOB_FREQUENCY * (0.35 + lastMoveAmp)
    idleTime = idleTime + dt

    local s1 = math.sin(bobPhase)
    local s2 = math.sin(bobPhase * 2)

    local bob = CFrame.new(
        s1 * Settings.BOB_SIDE * lastMoveAmp,
        math.abs(s2) * Settings.BOB_UP * lastMoveAmp,
        s2 * Settings.BOB_FORWARD * lastMoveAmp
    ) * CFrame.Angles(
        s1 * Settings.BOB_PITCH * lastMoveAmp,
        s1 * Settings.BOB_YAW * lastMoveAmp,
        s2 * Settings.BOB_ROLL * lastMoveAmp
    )

    -- ---------- Дыхание --------------------------------------------
    local idle = CFrame.new(
        math.sin(idleTime * 1.15) * Settings.IDLE_SWAY_POS,
        math.sin(idleTime * 1.73) * Settings.IDLE_SWAY_POS * 0.7,
        0
    ) * CFrame.Angles(
        math.sin(idleTime * 0.93) * Settings.IDLE_SWAY_ROT,
        math.sin(idleTime * 1.31) * Settings.IDLE_SWAY_ROT * 0.6,
        math.sin(idleTime * 0.71) * Settings.IDLE_SWAY_ROT * 0.8
    )

    -- ---------- Инерция от поворота мыши/головы --------------------
    -- Два источника: сырая дельта мыши И реальный поворот камеры.
    -- Второй нужен, чтобы свай работал на геймпаде, таче и без LockMouse.
    local mouseDelta = UserInputService:GetMouseDelta()

    local camYawImpulse, camPitchImpulse = 0, 0
    local curLook = cam.CFrame.LookVector
    if lastLookVector then
        local d = curLook - lastLookVector
        camYawImpulse   = math.clamp(-d.X * Settings.LOOK_CAMERA_GAIN,
            -Settings.LOOK_IMPULSE_CLAMP, Settings.LOOK_IMPULSE_CLAMP)
        camPitchImpulse = math.clamp( d.Y * Settings.LOOK_CAMERA_GAIN,
            -Settings.LOOK_IMPULSE_CLAMP, Settings.LOOK_IMPULSE_CLAMP)
    end
    lastLookVector = curLook

    local decay = 1 - math.clamp(dt * Settings.LOOK_RETURN, 0, 1)
    lookYaw   = (lookYaw   + camYawImpulse   - mouseDelta.X * Settings.LOOK_SWAY) * decay
    lookPitch = (lookPitch + camPitchImpulse + mouseDelta.Y * Settings.LOOK_SWAY) * decay
    lookYaw   = math.clamp(lookYaw,   -Settings.LOOK_MAX, Settings.LOOK_MAX)
    lookPitch = math.clamp(lookPitch, -Settings.LOOK_MAX, Settings.LOOK_MAX)
    local look = CFrame.Angles(lookPitch, lookYaw, 0)

    -- ---------- Дуга при перекидывании руки ------------------------
    local arc = math.sin(blend * math.pi)
    local swapArc = CFrame.new(0, arc * Settings.SWAP_ARC_LIFT, 0)
        * CFrame.Angles(0, arc * Settings.SWAP_ARC_YAW, 0)

    -- ---------- Отдача ---------------------------------------------
    recoil     = math.max(0, recoil - dt * Settings.RECOIL_RETURN)
    flashAlpha = math.max(0, flashAlpha - dt / math.max(Settings.MUZZLE_FLASH_TIME, 0.001))

    local recoilCF = CFrame.new(
        0,
        recoil * Settings.RECOIL_KICK_UP,
        recoil * Settings.RECOIL_KICK_BACK
    ) * CFrame.Angles(recoil * Settings.RECOIL_PITCH, 0, 0)

    -- ---------- Финальный CFrame -----------------------------------
    local baseOffset = Settings.LEFT_OFFSET:Lerp(Settings.RIGHT_OFFSET, blend)

    local baseCF = cam.CFrame
        * baseOffset
        * bob
        * idle
        * look
        * swapArc
        * recoilCF

    if builder then
        builder:Apply(baseCF, blend, flashAlpha)
    end
end

    тике PlayerModule успевает один кадр показать третье лицо и дёрнуть камеру.

    Что делает:
      * LockFirstPerson для всех, кто зайдёт ПОСЛЕ старта сервера;
      * отключает Shift-Lock (иначе камера уезжает в плечо);
      * на всякий случай дублирует Min/MaxZoomDistance на каждого Player
        и на каждый респавн (PlayerModule иногда перечитывает значения);
      * всё через pcall -> не упадёт, если Roblox переименует свойство.

    НЕ трогает: CharacterAutoLoads, Humanoid, анимации, Tools, DataStores.
    Актуально: ноябрь 2026 / Roblox Studio / Luau.

local Players       = game:GetService("Players")
local StarterPlayer = game:GetService("StarterPlayer")

local function forceStarterPlayer()
    pcall(function()
        StarterPlayer.CameraMode = Enum.CameraMode.LockFirstPerson
    end)
    pcall(function()
        StarterPlayer.EnableMouseLockOption = false
    end)
    -- На некоторых каналах эти два свойства живут и на StarterPlayer,
    -- на некоторых только на Player -> потому pcall, а не прямой вызов.
    pcall(function()
        StarterPlayer.CameraMinZoomDistance = 0
    end)
    pcall(function()
        StarterPlayer.CameraMaxZoomDistance = 0
    end)
end

local function forcePlayerZoom(player)
    pcall(function()
        player.CameraMinZoomDistance = 0
        player.CameraMaxZoomDistance = 0
    end)
end

local function onPlayerAdded(player)
    forcePlayerZoom(player)
    player.CharacterAdded:Connect(function()
        forcePlayerZoom(player)
    end)
end

forceStarterPlayer()
Players.PlayerAdded:Connect(onPlayerAdded)

-- Уже онлайн (важно для Studio «Play» с заранее созданным игроком)
for _, p in ipairs(Players:GetPlayers()) do
    onPlayerAdded(p)
end

print("[FP Pistol][Server] LockFirstPerson включён, Shift-Lock выключен.")
